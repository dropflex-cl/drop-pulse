# UgcStepper

Los 5 pasos del video UGC: Guion, Imágenes clave, Clips, Montaje, Video final.

- **Qué provees:** `current` (1–5), `vertical` (escritorio), `notes` (estado de cada paso en vertical).
- Hecho: círculo lleno con check; actual: anillo de acento y `aria-current="step"`.
- Contexto y casos de uso: `creativos.md`.
