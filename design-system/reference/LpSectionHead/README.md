# LpSectionHead

Encabezado de sección de la landing: etiqueta en `primary`, título y bajada.

- **Qué provees:** `eyebrow`, `title`, `lead`, `center`.
- La etiqueta nombra la sección para el visitante ("El problema", "Cómo funciona"); la estructura AIDA es interna y no se muestra.
- Título: 24/30 en móvil, 32/38 (`type-section`) en escritorio; bajada `type-lead`.
