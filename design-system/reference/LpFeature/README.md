# LpFeature

Un beneficio con su prueba: una pieza de la app, nunca una cifra inventada.

- **Qué provees:** `icon`, `title` (el resultado para el comerciante), `text` (cómo lo logra), `children` (la demo).
- Ícono en `primary-soft`: es el único lugar de la landing donde el acento decora, porque señala el beneficio.
- No usar estadísticas, logos de clientes ni testimonios que no existan. Cuando haya testimonios reales, van en una sección propia con nombre, tienda y permiso.
