# LpCta

Cierre de la landing (Acción): fondo `foreground`, una sola acción y la garantía de control.

- **Qué provees:** `title`, `lead`, `cta`, `fine`.
- El título dice el resultado inmediato ("revisa tu primer producto mejorado hoy"), la bajada baja la fricción (tiempo, sin empezar de cero) y la letra chica repite la promesa de control. Nunca urgencia falsa.
