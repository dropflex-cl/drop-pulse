# Notice

Aviso sobre una lista o un bloque: algo cambió o falta un dato.

- **Qué provees:** `tone` (`warning` | `info`), `icon`, `title`, `body`, `action`.
- `warning` para lo que afecta el resultado (textos desactualizados, un obligatorio pendiente); `info` para lo que el comerciante debe completar (datos que la IA no tiene).
- Va arriba de la tarjeta o la lista a la que se refiere, nunca como toast: tiene que seguir visible.
