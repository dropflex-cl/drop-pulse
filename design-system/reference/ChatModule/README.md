# ChatModule

El chat de WhatsApp de un ángulo, presentado como formato aparte y no como un concepto más.

- **Qué provees:** `state` (`new` | `created` | `review` | `approved`).
- Borde punteado y fondo apagado para distinguirlo de los conceptos; va al pie de cada `AngleGroup`. Al crearlo abre la hoja con `ChatConsent`.
- Contexto y casos de uso: `creativos.md`.
