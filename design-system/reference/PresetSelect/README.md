# PresetSelect

Selector de plantillas que precargan toda la configuración; todo sigue siendo editable.

- **Qué provees:** `value`, `options` (`{ value, label }`, filtradas por estructura), `source` (qué carga), `modified` (número de campos cambiados), `label`.
- Plantillas del sistema (por ejemplo "Testeo ABO · 1 creativo por conjunto") y plantillas propias ("Mi plantilla…"), separadas en grupos dentro del selector.
- Con cambios sobre la plantilla aparece la barra "N cambios · Restablecer · Guardar como plantilla". Cada sección editada muestra "Editado".
- Cambiar de plantilla con cambios hechos pide confirmación.
