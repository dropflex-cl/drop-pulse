# AssistantButton

Abre el asistente del producto limitado a una etapa. Va en la barra superior junto a `AiCostChip`.

- **Qué provees:** `scope` (etapa a la que se limita, se lee en el nombre accesible), `label` (texto visible; en escritorio «Asistente»).
- Sin etiqueta es un botón redondo de 40 px con el destello en color de acento.
- Contexto y casos de uso: `creativos.md`.
