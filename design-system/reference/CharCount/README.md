# CharCount

Contador de caracteres o palabras contra el límite del bloque.

- **Qué provees:** `count`, `limit`, `unit` (`caracteres` | `palabras`), `live` (anuncia cambios mientras se edita).
- Pasado el límite: texto `destructive` con ícono, y el borde del campo cambia a `destructive`. "Guardar y aceptar" se deshabilita: el límite es el mismo que valida el código.
