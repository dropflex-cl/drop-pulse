# ScriptShot

Una toma del guion del UGC.

- **Qué provees:** `n`, `kind` (`talk` | `broll`), `time`, `line` (lo que dice o lo que se ve), `onscreen`, `changed` (se genera de nuevo), `editing`.
- Las habladas se generan en Seedance con voz y las de apoyo en Kling. La persona muestra el producto: no dice ser clienta ni cuenta resultados propios.
- Contexto y casos de uso: `creativos.md`.
