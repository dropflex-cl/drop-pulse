# MontagePackage

El paquete JSON para montar el video en local con `scripts/ugc-montage.py`.

- **Qué provees:** `clips`, `expiresIn`, `expired`, `disabled`.
- Las URLs firmadas duran 24 h. Vencidas: «Generar el paquete de nuevo», sin volver a crear los clips.
- Contexto y casos de uso: `creativos.md`.
