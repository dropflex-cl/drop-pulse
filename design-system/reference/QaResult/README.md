# QaResult

Resultado del QA que hace Claude con visión sobre una pieza.

- **Qué provees:** `issues` (lista de textos; vacía = sin detalles), `okLabel` (por defecto «Texto y producto revisados»; en imágenes clave, «Manos, cara y producto OK»).
- Con detalles: fondo de aviso, «Revisa: N detalles» y la lista. Nunca bloquea aprobar: el comerciante decide.
- Contexto y casos de uso: `creativos.md`.
