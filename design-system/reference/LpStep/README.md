# LpStep

Un paso de "Cómo funciona", con una pieza real de la app como prueba.

- **Qué provees:** `n`, `title`, `text`, `children` (un componente del sistema con datos de ejemplo: `ConnectionCard`, `AngleCard`, `ReviewCard`, `DecisionRow`).
- La demo es ilustrativa: `aria-hidden` y sin interacción. Mostrar la app real en vez de capturas o íconos genéricos es la promesa de la landing.
