# ChipInput

Campo de valores múltiples para países, regiones excluidas o intereses.

- **Qué provees:** `label`, `values`, `placeholder`, `hint`, `disabled`.
- Escribir sugiere desde el catálogo de Meta (búsqueda con debounce); Enter o coma agrega; cada chip se quita con su x de 24px (área de 44px en la fila).
- Intereses queda deshabilitado con público abierto (Advantage+) y explica por qué.
