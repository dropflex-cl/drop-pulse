# Cómo se usa

Sección `df-usage-steps`. Metafield `dropflex.usage_steps`; contrato en `content.ts`.

Activada por defecto. Sin contenido o pruebas requeridas muestra un estado vacío visible y honesto. La elección de variantes conserva el contenido e imágenes de cada ángulo. Nunca presenta datos de ejemplo en la tienda.

* Una idea principal por sección, textos cortos y concretos para móvil.
* No envíes contenido ficticio para rellenar: sin evidencia se publica el estado vacío.
* Todos los fact_id deben pertenecer a hechos aprobados y verificados del producto.
