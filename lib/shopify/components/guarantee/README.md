# Compra con confianza

Sección `df-guarantee`. Metafield `dropflex.guarantee`; contrato en `content.ts`.

Activada por defecto. Sin contenido muestra un estado vacío visible. La elección de variantes conserva el contenido e imágenes de cada ángulo. Nunca presenta datos de ejemplo en la tienda.

* Una idea principal por sección, textos cortos y concretos para móvil.
* Los precios, ahorros, pago, envío, devoluciones y garantía se leen de datos publicados. No escribir números ni nuevas políticas en el texto.


## Dirección editorial vigente

Desarrolla la transformación del hook desde la función de esta sección. El titular comunica una razón para seguir leyendo; las escenas, explicaciones y objeciones refuerzan el mismo motivo de compra, sin duplicación literal. Consulta [la escritura de PDP](../../../../plugins/dropflex-optimizer/skills/optimize-product/references/pdp-writing.md). Los ejemplos de `content.ts` son ilustraciones editoriales de productos concretos, no datos de otro producto. Los campos, límites, medios y decisiones vigentes se conservan.

## Superficie y movimiento

La presentación usa los tonos del acento existente y el revelado compartido de entrada única. Reglas, medidas y contraste: [superficies de tienda](../../../../design-system/storefront-surfaces.md). Los colores explícitos del editor se conservan donde existen. No cambia el contrato de contenido ni la selección de archivos.
